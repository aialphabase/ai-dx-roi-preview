# ミライニュース 収録シーン

台本の「画面」欄（資料A〜K）を、セミナースライドと同じ作りの動く画面にしたもの。
Final Cut で収録する映像に、そのまま重ねたり差し込んだりするために作っている。

- 正本は `ep<番号>.json`。HTML は生成物なので直接さわらない。
- 組み直し: `python3 build_scenes.py 27`
- 静止画の書き出し: `bash make_stills.sh 27` → `ep27/stills/<資料記号>-<状態番号>.png`（1920×1080）
- 公開URL: `https://aialphabase.github.io/ai-dx-roi-preview/projects/mirai-ops/scenes/ep27/`

## 画面の操作

| キー | 動き |
| --- | --- |
| → / Space | 次の状態へ。状態を出し切ったら次のシーンへ |
| ← | ひとつ戻る |
| f | 全画面（収録はこれで1920×1080に合わせる） |
| u | ページ番号を出す（収録中は消しておく） |
| i | 資料記号・台本の読み位置・尺の目安を出す |

URLで直接呼べる。`?s=7` は7枚目から、`?s=7&step=2` は7枚目の2状態目、`?full=1` は全状態を出した静止。

## 動きの種類

| 資料 | 形 | 動き |
| --- | --- | --- |
| C | バーが伸びる | 3本を1本ずつ、右へ伸ばす（1秒） |
| G | 線が伸びる | SVGのパスを左から描く（1.8秒）→ 点と数字 → 右の2枚 |
| J | 1つずつ出す | A・B・Cを順に。Cだけ金色＋「最有力」 |
| D・F・I・K | 段階表示 | 強調やカードを1つずつ出す |
| A・B・E・H | 静止 | フェードインのみ |

## 収録の型（Final Cut）

1. 先に台本を確定させる（`../script/ep27.html`）。このJSONは台本の「画面」欄を写しただけの状態を保つ。
2. `f` で全画面にして、読み上げに合わせて → を押しながら画面収録する。1シーンずつ録って、FCPで並べるのがいちばん楽。
3. 動きがいらないところは `stills/` のPNGを置く。FCP側でのズームやフェードはここに掛ける。
4. テロップはFCP側。画面の文字は「資料に書いてあること」だけにして、話し言葉のテロップとぶつけない。
5. 尺は台本の秒数が目安。1秒あたり5.2文字で計算してある。

## Final Cut への渡し方（合成を重くしない）

重さの正体は、H.264/HEVC の映像を2枚同時に復号して合成すること。ProRes はコマ単位の圧縮で復号が軽く、
Final Cut はこれを前提に作られている。だから「重ねる素材は ProRes で作る」が答えになる。

| 使い方 | 作り方 | 向いている資料 |
| --- | --- | --- |
| 全画面で差し込む（重ねない） | `bash render_clips.sh 27 C` → ProRes 422 HQ | A・B・C・E・H・K など画面いっぱいの資料 |
| 話者の上に重ねる（背景を抜く） | `bash render_clips.sh 27 G alpha` → ProRes 4444（アルファ付き） | G の線、I の強調、テロップ的な部品 |
| 動かさない | `bash make_stills.sh 27` → PNG | 読み上げが長く、画が止まっていていい所 |

- 出来る場所: `ep27/clips/<資料記号>.mov`（1920×1080・30fps）。Gitには入れない。
- 尺は `ep27/timeline.json` の `render_ms`。台本の秒数に足りない分は、最後のコマで止めて伸ばす。
- 書き出しは Chrome を1つ立ち上げて時刻を進めながらコマを撮る方式（`render_frames.mjs`、Node 22）。
  5秒のクリップで約17秒、1回分11本で5分ほど。
- 重ねる側の素材（収録した本編）も ProRes にそろえる、またはFCPの「メディアを最適化」を通すと、
  重ねたまま再生しても止まらない。それでも重いときは複合クリップにしてレンダリングする。

## 色（番組ごとのイメージカラー）

形は共通のまま、色だけ差し替えられる。`?theme=news|literacy|crypto`、または JSON の `meta.theme`。

| テーマ | 主色 / 副色 | 想定 |
| --- | --- | --- |
| news | 金 / 青緑 | ウィークリーミライニュース（既定） |
| literacy | 生成り / 若草 | ミライテラシー |
| crypto | ミント / 紫 | クリプト未来ニュース |

色は CSS の先頭（`:root` と `body[data-theme="..."]`）にまとまっている。`--key` が主色、`--sub` が副色、
`--bg1〜3` が背景。新しい番組を足すときはここに1ブロック書き足す。

## 次の回の作り方

`ep27.json` をコピーして数字と言葉を入れ替える。新しい見せ方が要るときだけ `build_scenes.py` に種類を足す。
数字は台本にあるものだけを使う。台本にない中間の値は描かない（G の 9/16・9/17 に値を置いていないのはこのため）。
