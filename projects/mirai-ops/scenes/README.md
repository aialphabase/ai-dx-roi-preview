# ミライニュース 収録シーン

台本の「画面」欄（資料A〜K）を、セミナースライドと同じ作りの動く画面にしたもの。
Final Cut で収録する映像に、そのまま重ねたり差し込んだりするために作っている。

- 正本は `ep<番号>.json`。HTML は生成物なので直接さわらない。
- 組み直し: `python3 build_scenes.py 27`
- 静止画の書き出し: `bash make_stills.sh 27` → `ep27/stills/<資料記号>-<状態番号>.png`（1920×1080）
- 公開URL: `https://aialphabase.github.io/ai-dx-roi-preview/projects/mirai-ops/scenes/ep27/`

## 画面の操作

| キー | 動き |
| --- | --- |
| → / Space | 次の状態へ。状態を出し切ったら次のシーンへ |
| ← | ひとつ戻る |
| f | 全画面（収録はこれで1920×1080に合わせる） |
| u | ページ番号を出す（収録中は消しておく） |
| i | 資料記号・台本の読み位置・尺の目安を出す |

URLで直接呼べる。`?s=7` は7枚目から、`?s=7&step=2` は7枚目の2状態目、`?full=1` は全状態を出した静止。

## 動きの種類

| 資料 | 形 | 動き |
| --- | --- | --- |
| C | バーが伸びる | 3本を1本ずつ、右へ伸ばす（1秒） |
| G | 線が伸びる | SVGのパスを左から描く（1.8秒）→ 点と数字 → 右の2枚 |
| J | 1つずつ出す | A・B・Cを順に。Cだけ金色＋「最有力」 |
| D・F・I・K | 段階表示 | 強調やカードを1つずつ出す |
| A・B・E・H | 静止 | フェードインのみ |

## 収録の型（Final Cut）

1. 先に台本を確定させる（`../script/ep27.html`）。このJSONは台本の「画面」欄を写しただけの状態を保つ。
2. `f` で全画面にして、読み上げに合わせて → を押しながら画面収録する。1シーンずつ録って、FCPで並べるのがいちばん楽。
3. 動きがいらないところは `stills/` のPNGを置く。FCP側でのズームやフェードはここに掛ける。
4. テロップはFCP側。画面の文字は「資料に書いてあること」だけにして、話し言葉のテロップとぶつけない。
5. 尺は台本の秒数が目安。1秒あたり5.2文字で計算してある。

## 次の回の作り方

`ep27.json` をコピーして数字と言葉を入れ替える。新しい見せ方が要るときだけ `build_scenes.py` に種類を足す。
数字は台本にあるものだけを使う。台本にない中間の値は描かない（G の 9/16・9/17 に値を置いていないのはこのため）。
