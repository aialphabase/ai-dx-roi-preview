# ミライカルテ 資産構築シミュレーター A/Bプロトタイプ

アンケート回答特典として配布できる、ブラウザ完結の静的プロトタイプです。ビルド処理や外部ライブラリは不要で、GitHub Pagesへそのまま配置できます。

## 収録内容

- `index.html`: A/B比較トップ
- `pattern-a-dashboard.html`: A案 即時計算ダッシュボード
- `pattern-b-roadmap.html`: B案 伴走型ライフロードマップ
- `assets/sim-core.js`: 共通計算・診断・CRMスコアリング
- `docs/mvp-integration.md`: Laravel / Sheets / LINE接続時の実装メモ
- `docs/ab-test-plan.md`: 配信・KPI・判定ルール
- `docs/requirements-map.md`: 企画要件と画面実装の対応表

## A案

入力値を変更するたび、目標年齢時点の見込み資産、目標との差、必要積立額、資産推移、診断タイプ、推奨アクション、CRMスコアが即時更新されます。

主な検証KPI:

- 特典URLの起動率
- 入力値を変更した割合
- 診断結果まで到達した割合
- 相談希望率

## B案

現在地、ライフイベント、資産形成条件、関心テーマを4ステップで入力し、100歳までの資産推移、イベント負担、12か月計画、診断タイプ、CRMスコアを生成します。

主な検証KPI:

- ステップ別離脱率
- 診断完了率
- 入力テーマ数
- 個別相談希望率
- 再診断率

## 計算上の前提

- 運用期間中は月次複利で概算します。
- B案の老後期間は、入力利回りと年4%の低い方を使用します。
- 老後は「希望生活費 - 公的年金見込み」を年次で取り崩します。
- 教育費はピーク年齢を中心とする8年間へ均等配分します。
- 税金、手数料、インフレ、ローン返済、保険はMVPでは簡略化しています。
- 15%は比較用の高変動シナリオであり、期待値や推奨値ではありません。

## GitHub Pagesでのプレビュー

1. このフォルダの中身をリポジトリ直下へ配置します。
2. GitHubの `Settings > Pages` で対象ブランチのルートを公開元にします。
3. 発行されたURLの `index.html` からA/Bを選べます。
