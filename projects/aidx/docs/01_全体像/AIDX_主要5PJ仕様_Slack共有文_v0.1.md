## Slack投稿文(コピー用)

```
📌 AIDX 主要5PJ 仕様共有(Claude Cowork版)

先日共有した全体像(渡す→任せる→受け取る)の続きです。各PJの中身を簡単にまとめました。詳細プロンプトは PJ別プロンプト集(v1.0) を参照してください。

*共通ルール(全PJ共通)*
• 入力にない事実・数値・期限・担当は作らない → 不明は「要確認」
• 「事実」と「意見・見立て・推測」を必ず分ける
• 契約・金額・法務・個人情報に関わる最終判断は必ず人が行う(AIが出すのは下書きまで)
• 各PJに品質確認プロンプト(QA-0X)がセットになっている(納品本数には数えない)

*PJ-01 議事録・決定事項・TODO化*
入力:会議メモ/文字起こし → 出力:決定事項・未決事項・TODO(担当/期限/根拠)を分けて整理
ゴール:会議後30分以内に、決定・未決・担当・期限を追跡できる状態にする

*PJ-02 日報・CRM入力支援*
入力:面談メモ → 出力:日報+CRM登録案(顧客の発言と営業の見立てを分離)
ゴール:面談メモから日報とCRM登録案を5分以内で作る

*PJ-03 営業資料・提案書作成*
入力:ヒアリング内容+商品情報 → 出力:提案構成(10枚以内)+本文初稿、主張ごとに根拠・出典付き
ゴール:ヒアリング後60分以内に提案構成と初稿を作る

*PJ-04 FAQ・社内ナレッジ整備*
入力:社内資料+問い合わせ履歴 → 出力:FAQ候補(根拠・公開範囲・確認担当・状態付き)、資料間の矛盾は統合せず両方提示
ゴール:頻出質問50件までを根拠・責任者付きで管理する

*PJ-05 メール・問い合わせ回答*
入力:問い合わせ原文+回答根拠 → 出力:返信下書き+内部確認メモ、AIは送信しない
ゴール:受信後15分以内に確認ルールに沿う返信案を作る

*運用上のポイント*
すべて「下書き」です。各PJの人手確認チェックリストを通してから確定・送信してください。質問や気になる点はこのスレッドへどうぞ。
```
