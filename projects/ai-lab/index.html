このページへの追加ルール

ツール・取り組みを追加するときは、HTML内の TOOLS 配列にオブジェクトを1件足すだけ(集計・絞り込み・比較表は自動反映)。フィールドは name(名称) / cat(カテゴリ: 業務ツール・AI活用・自動化・検証比較のいずれか、新設可) / status(live=運用中・demo=デモ検証中・study=検討中・idea=構想) / desc(2行以内の説明) / cost(コスト目安) / alt(置き換え対象・比較先) / links(url があれば公開リンク、なければ place に「社内アーティファクト」等の所在を書く)。 公開Pagesに置く版と社内アーティファクト版は同一ファイル(このHTML)を正とし、更新時は両方に反映する。素材・経緯のMarkdownはプロジェクト/aidx-docs側に置く。
