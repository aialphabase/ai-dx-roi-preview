# 要求と実装の対応表

## 企画情報から反映した要素

| 要求 | A案 | B案 |
|---|---|---|
| 自分の現在地 | 目標達成率と不足額 | 100歳までの資産寿命 |
| 将来の不足・課題 | 目標との差、必要積立額 | 不足発生年齢、イベント負担 |
| 優先テーマ | 診断タイプから3件提示 | ライフイベント込みで3件提示 |
| 次の一手 | 即時アクション | 12か月・四半期ロードマップ |
| 何度でも更新 | 全項目を即再計算 | 端末内の入力途中保存 |
| 資産形成 | 積立・利回り・目標資産 | 積立・老後取り崩し |
| 収入・キャリア | 年収、AI、副業 | 年収、働き方、AI、副業 |
| 不動産 | 関心テーマと提案タグ | 住宅イベントと不動産関心 |
| 暗号資産 | 関心テーマ | 高変動資産の上限比率 |
| 事業・法人化 | 働き方、法人化関心 | 働き方、法人化・節税関心 |
| CRMスコア | 4スコアを即表示 | 4スコアを結果で表示 |
| 高温度通知 | 条件一致でON | 条件一致でON |

## 参考シミュレーターから反映した質問群

- 本人: 年齢、年収、現在資産
- 配偶者・世帯: 世帯構成、配偶者収入
- 子ども: 人数、教育費、教育費の山
- 住まい: 購入・住み替え年齢、自己資金
- セカンドライフ: リタイア年齢、希望生活費、公的年金見込み
- ライフイベント: 車購入と買い替え周期

初期MVPでは結婚式、旅行、ペット、介護、相続額などを省き、完了時間を約3分に抑えています。採用案決定後、条件分岐で必要な質問だけ追加する想定です。

## 診断タイプ

- 収入拡張
- 資産形成準備
- 安定構築
- 不動産活用
- 法人・事業成長
- 守り優先
- 学習準備
- 専門家伴走

主タイプと副タイプを組み合わせ、「収入拡張 × 資産形成準備」のように表示します。

## CRMスコア

- 資産形成ニーズ
- 投資意欲
- 提案適合度
- LTV予測

画面側のスコアはプロトタイプ用です。本番ではLaravel側で同じ入力から再計算し、ルールの版番号を保存します。
