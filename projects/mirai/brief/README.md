# ミライ週次ブリーフ（会員向け・データ分離型）

公開URL: https://aialphabase.github.io/ai-dx-roi-preview/projects/mirai/brief/
（確認は `?nocache=YYYYMMDDHHMM` 付き。特定の号は `?week=2026-W36`）

## 仕組み

- `index.html` … 表示テンプレート。**毎週触らない**
- `data/index.json` … 号の一覧と最新号の指定
- `data/<週ID>.json` … その号の中身（今週の形・傾き・話題表・市場データ・確認ポイント・1問）

週次更新は **JSONを1本追加して index.json を書き換えるだけ**。HTMLの編集は不要。
過去号はそのまま残り、ヘッダーの号セレクタ（2号以上で自動表示）がアーカイブになる。

## 毎週の手順（火曜）

1. スキル/Claudeで週次観測 → `data/2026-W37.json` を生成（前号の `answerCheck` に答え合わせを記入）
   - **ETFフロー欄（`etf`）も毎週更新**：週間純流入・単日の目立った流出入・同期間の価格。`flows` に週次の数値（百万ドル単位）を積むと棒グラフでアーカイブされる
2. `data/index.json` の `latest` を新週IDに変更し、`weeks` に1行追加
3. ブランチ → 確認（?nocache付き）→ mainへマージ＝公開
4. HQ「現在地」へ1行追記

※ GitHubのWeb画面（Add file / Edit）だけでも完結するので、開発環境がない担当者でも更新可能。

## ゲート（このページに載せてよいもの）

- 載せる: 指標（傾き・話題の言及数・混雑度・温度差）、公開市場データ、論点、今週の1問
- 載せない: ソース名（S-01/S-02等のIDと種別まで）、発言の引用、個別銘柄の売買判断
- 免責文はテンプレートに固定済み（全号共通・変更しない）

## answerCheck の書式（第2号から使う）

```json
"etf": {
  "title": "見出し", "lede": "1行",
  "stats": [{"label": "…", "value": "+9.2億ドル", "dir": "in|out|px"}],
  "flows": [{"label": "8/24週", "v": 924}, {"label": "8/31週", "v": -150}],
  "unit": "M$",
  "note": "流入と価格の関係の解説", "learn": "読み方の練習", "source": "出典"
},
"answerCheck": [
  {"t": "先週の確認ポイントの見出し", "d": "実際どうなったか。<b>外れた場合ほど丁寧に</b>、どのルール・見立てがどう効いたかを書く"}
]
```
