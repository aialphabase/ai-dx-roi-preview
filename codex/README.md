# AI DX ROI Preview

GitHub Pagesでチーム確認するための静的プレビュー版です。

## 内容

- `index.html`: プレビューサイト本体
- `assets/`: ポスター画像・字幕
- `videos/`: Web表示用動画3本
- `.nojekyll`: GitHub Pages向け設定

## 公開予定URL

`https://aialphabase.github.io/ai-dx-roi-preview/`

## 注意

- 検証用のため `noindex,nofollow,noarchive` を設定しています。
- ROI数値はモデルケースであり、効果を保証するものではありません。
- 制作元のNext.js版とWordPress本番版は変更していません。
